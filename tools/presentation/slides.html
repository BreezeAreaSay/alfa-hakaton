Кабинет клиента

Сколько одобрят и сколько это стоит — ещё до заявки

  • Предложение до заявки. «Вам уже доступно» — по данным компании, с пометкой «предварительно»
  • Сколько одобрят по выписке. Лимит и прогноз кассового разрыва на — за секунды, без заявки
  • Подбор от задачи. карточками или описание своими словами; продукты — от меньшей ставки, с платежом и переплатой
  • Заявка почти без ввода. Реквизиты — из ЕГРЮЛ/ЕГРИП, финансы — из ГИР БО, БКИ и оборотов по счёту

Безопасность и качество

Безопасность — по умолчанию, качество — в автотестах

Безопасность

  • : клиент, аналитик, администратор; права проверяются на каждом маршруте, клиент видит только заявки своей компании
  • Перебор паролей: после вход блокируется на , подмена адреса не помогает

Что делает модель

  • Разбирает описание задачи: цель, сумма и срок; клиент видит распознанное и может поправить
  • Пишет сводку для аналитика:  пунктов «сильные стороны / риски» с пометкой «не решение»
  • Только по действию человека: конвейер модель не вызывает, её скорость не влияет на обработку заявок

Почему это безопасно

  • Решают правила: скоринговая карта и кредитная политика, в ручных случаях — аналитик
  • Только открытые веса: Qwen3 4B локально или любой провайдер с API в формате OpenAI — адрес, ключ и модель в .env
  • Работает и без модели: по умолчанию выключено; правила верно разбирают из фраз эталонного набора, придуманных значений —
  • Минимум данных: название компании, ИНН и имена в модель не уходят

Эффект для банка

Что меняется для банка — честно о цифрах

«Было» — допущения из открытых источников. «Стало» — то, что уже считает страница «Показатели» на синтетических данных стенда: механика подсчёта, а не прогноз портфеля.

ПоказательБыло — допущениеСтало — считает стенд
Доля автоматических решений %: каждую заявку рассматривает сотрудник из компаний демо-набора решаются без аналитика; набор показывает все исходы, поэтому это не прогноз
От отправки до решенияот недели ожидания звонка до месяца до предварительного одобрения — по отзываммедиана  с, 95 % —  с при одновременно
Конверсия «предложение → принято»не измеряется: отказ бинарный, клиент уходитсчитается, включая контрпредложения, — показатель для пилота
Время аналитика на заявкунет данных в открытых источниках, замер до пилотамедиана рассмотрения и просрочки срока — на странице «Показатели»

Экономия времени аналитика = число автоматических решений × время на типовую заявку. Это формула, а не цифра: число появится в пилоте.
