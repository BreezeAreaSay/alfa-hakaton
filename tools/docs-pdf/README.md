# Документация в PDF

Собирает документацию проекта из Markdown в один файл `docs/Документация-проекта.pdf`: обложка, содержание с переходами и номерами страниц, документы по порядку, диаграммы Mermaid, колонтитулы с названием документа и номером страницы.

## Как пересобрать

```bash
cd frontend && npm ci && cd ..      # шрифт Onest, если frontend/node_modules ещё нет
cd tools/docs-pdf
npm ci
npx playwright install chromium     # один раз: браузер для Playwright
npm run build
```

Сборка занимает 15–20 секунд. Генератор печатает каждую диаграмму с выбранной раскладкой и масштабом, путь к PDF, число страниц и в конце — предупреждения.

Если Chromium уже установлен, скачивать браузер не нужно — укажите путь к нему:

```bash
PW_CHROMIUM_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npm run build
```

## Что нужно

| Что | Зачем |
|---|---|
| Node.js 22.12 или новее | Генератор |
| `frontend/node_modules` (`npm ci` в `frontend`) | Шрифт Onest из `@fontsource/onest` |
| Chromium для Playwright 1.64.1 | Вёрстка и печать в PDF |
| `pdfinfo` из poppler-utils | Номера страниц в содержании. Необязательно: без него переходы в содержании работают, но номеров нет. Ubuntu и Debian — `sudo apt install poppler-utils`, macOS — `brew install poppler` |

## Что входит в PDF

Порядок задан списком `DOCUMENTS` в [build.mjs](build.mjs):

1. `README.md` — раздел «Обзор проекта»;
2. `docs/product.md`, `requirements.md`, `architecture.md`, `process.md`, `credit-policy.md`, `data-model.md`, `api.md`, `test-scenarios.md`, `ai.md`, `design.md`, `deploy.md`;
3. `docs/demo-mode.md` — только если файл есть;
4. `docs/research/interview-guide.md`.

`docs/plan.md` (устаревший рабочий черновик) и `THIRD_PARTY_NOTICES` (длинные сгенерированные таблицы лицензий) не входят — на странице содержания на них ссылки в репозитории.

Добавить документ — строка в `DOCUMENTS`; с `optional: true` он включается, только если файл существует.

## Параметры

Аргументы передаются через `--`: `npm run build -- --strict`.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `--out <путь>` | `docs/Документация-проекта.pdf` | Куда записать PDF, путь от корня репозитория |
| `--github-base <адрес>` или `DOCS_GITHUB_BASE` | `https://github.com/stonebridgeway/alfa-hakaton/blob/main/` | Основа ссылок на файлы репозитория. Для сдаваемой версии — `…/blob/v1.0.0/` |
| `--strict` | выключено | Код выхода 1, если есть предупреждения |
| `--keep-html` | выключено | Оставить промежуточный HTML для отладки, путь печатается |
| `PW_CHROMIUM_PATH` | браузер Playwright | Путь к исполняемому файлу Chromium |
| `DOCS_VERSION` | последний git-тег, иначе `git describe --always` | Версия на обложке |
| `SOURCE_DATE_EPOCH` | текущая дата | Дата сборки на обложке — для воспроизводимой сборки |

## Как устроено

| Файл | Что делает |
|---|---|
| [build.mjs](build.mjs) | Список документов, обложка, содержание, запуск Chromium, номера страниц |
| [lib/markdown.mjs](lib/markdown.mjs) | Markdown → HTML (markdown-it): якоря заголовков по правилам GitHub, ссылки, таблицы, код |
| [page/browser.js](page/browser.js) | В браузере перед печатью: диаграммы Mermaid, подгонка диаграмм и таблиц |
| [page/style.css](page/style.css) | Вёрстка: A4, шрифт Onest, цвета дизайн-системы, колонтитулы, правила разрывов страниц |

- **Ссылки.** Между документами — переходы внутри PDF, в том числе на раздел (`process.md#статусы-заявки`). На другие файлы репозитория — ссылки на GitHub, папки открываются через `tree/`. Внешние ссылки не меняются. Если файла или раздела нет — предупреждение с файлом и строкой; ссылка на несуществующий файл остаётся текстом.
- **Диаграммы.** Mermaid рисует SVG прямо в странице. Для flowchart, state и ER генератор пробует раскладки dagre и ELK, у ER-диаграммы без `direction` — ещё и слева направо, и берёт ту, где текст крупнее (при почти равном размере — ELK, она аккуратнее). Диаграмма не обрезается: масштаб подбирается под ширину и высоту страницы. Если на книжной странице она мельче 50 %, а на альбомной заметно крупнее, она переносится на альбомную страницу вместе с заголовком. Под очень крупной диаграммой — подсказка увеличить масштаб просмотра: SVG остаётся векторным.
- **Шрифт.** Onest из `frontend/node_modules/@fontsource/onest`: наборы cyrillic и latin в начертаниях 400, 500, 700, а также latin-ext и math — только ради знаков ₽, →, ≈, ≥. Код — моноширинным шрифтом системы (JetBrains Mono, DejaVu Sans Mono, Menlo, Consolas).
- **Номера страниц в содержании.** PDF печатается, `pdfinfo -dests` сообщает страницы заголовков, номера подставляются, PDF печатается ещё раз. Колонка номеров фиксированной ширины, поэтому вёрстка не сдвигается.
- **Закладки.** PDF размечен (tagged) и содержит закладки по заголовкам.

## Предупреждения

| Сообщение | Что сделать |
|---|---|
| `файл «…» не найден — ссылка оставлена текстом` | Исправить ссылку в указанной строке или добавить файл |
| `раздел «#…» не найден` | Проверить якорь: он строится из текста заголовка, как на GitHub |
| `диаграмма не отрисована` | Синтаксическая ошибка Mermaid — текст ошибки виден и в PDF на месте диаграммы |
| `таблица … шире страницы` | Сократить таблицу или разбить её на две |
| `pdfinfo … не найден` | Установить poppler-utils, если нужны номера страниц в содержании |
