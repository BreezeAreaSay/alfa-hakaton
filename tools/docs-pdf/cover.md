## Как запустить и проверить

Нужны Docker с Compose v2 и интернет для первой сборки образов (около пяти минут); остальное стенд делает сам.

```bash
git clone {{repo_url}}
cd alfa-hakaton
git checkout {{ref}}
docker compose up -d --build --wait
```

Интерфейс: <http://localhost:8080>. Пошаговый сценарий проверки — раздел «Сценарий проверки» в README, 17 сценариев
с ожидаемыми результатами — `docs/test-scenarios.md`. Пароль у всех тестовых учётных записей — `admin`:

| Логин | Кто | Что показывает |
|---|---|---|
| `veter` | ООО «Северный ветер» | Автоодобрение, подписание и выдача кредита |
| `smirnova` | ИП Смирнова | Контрпредложение по овердрафту, прогноз кассового разрыва по выписке |
| `orlov` | ИП Орлов | Банк запрашивает выписку, затем одобряет |
| `vektor`, `analyst` | ООО «Вектор Логистик», кредитный аналитик | Ручное рассмотрение: досье, запрос информации, решение аналитика |
| `admin` | Администратор | Сбои внешних систем, сброс демо-данных, показатели конвейера |

## Что важно знать при проверке

- **Без платных сервисов и ключей.** Стенд работает автономно: внешние системы (ЕГРЮЛ/ЕГРИП, ФНС, ГИР БО, БКИ,
  данные банка, АБС) заменены симулятором с управляемыми сбоями. После сборки образов интернет не нужен.
- **ИИ-помощник необязателен и выключен по умолчанию.** Основной сценарий работает без модели. Включение —
  `docs/ai.md`: локальная Ollama (`qwen3:4b`, Apache 2.0) или любой сервис с открытыми весами и API в формате
  OpenAI через `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` в `.env`.
- **Безопасность проверена отдельно:** роли и доступ к чужим заявкам, защита входа от перебора паролей (в том числе
  от подмены адреса), тип загружаемых файлов по расширению, Content-Security-Policy и заголовки безопасности,
  журнал действий — `docs/architecture.md`, раздел «Безопасность», каждая мера покрыта тестом.
- **Допущения и упрощения** перечислены явно: `docs/process.md`, раздел «Упрощения», и `THIRD_PARTY_NOTICES`,
  раздел «Смоделированные интеграции». Подписание — простая электронная подпись паролем, выдача — через
  симулятор АБС, реальных платежей нет.
- **Автотесты:** 141 юнит-тест бэкенда и симулятора, 29 сценариев через API, 19 сценариев в браузере на стенде
  и в демо-версии без сервера, аудит доступности 16 экранов по WCAG 2.1 AA; запуск — `make test`, `make test-api`,
  `make e2e`, `cd e2e && npm run test:a11y`.
