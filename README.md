# Умный кредитный кабинет предпринимателя

Прототип цифрового кредитного конвейера для малого и микробизнеса. Кабинет клиента и рабочее место кредитного аналитика работают в одном процессе. Решение кейса хакатона «Альфа Будущее» от Альфа-Банка.

Проект в разработке. Инструкция по запуску появится вместе с кодом.
