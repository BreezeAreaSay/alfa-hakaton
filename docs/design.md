# Интерфейс

Кабинет и рабочее место аналитика собраны на дизайн-системе Альфа-Банка и сверены с alfabank.ru: клиент банка должен чувствовать себя в знакомом продукте.

## Дизайн-система

- Компоненты — [`@alfalab/core-components`](https://github.com/core-ds/core-components) (MIT): кнопки, поля, слайдеры, шаги, вкладки, плашки, модальные окна. Иконки — `@alfalab/icons-glyph` (MIT).
- Темы: `corp` — для клиентов-юрлиц и ИП (главная кнопка красная), `intranet` — для сотрудников банка (главная кнопка чёрная). Тема подключается в макете раздела ([Theme.tsx](../frontend/src/components/Theme.tsx)).
- Цвета — палитра `bluetint` дизайн-системы. Собственных цветов почти нет, всё на токенах.
- Логотип Альфа-Банка — знак «А» из открытого пакета дизайн-системы `@alfalab/icons-logotype` (MIT); организаторы разрешили фирменные знаки и цвета. Фирменные шрифты не используются: вместо Styrene — открытый Onest.

## Шрифт

Фирменные шрифты банка — Styrene UI и Alfa Interface Sans — распространяются по коммерческой лицензии, а ТЗ запрещает закрытые лицензии. Вместо них используется [Onest](https://fonts.google.com/specimen/Onest) (OFL 1.1): из свободных шрифтов с кириллицей он ближе всего к Styrene по рисунку — геометричные круглые «о», прямой хвост у «у», плоские «ножки» у «д», широкие пропорции. Сравнивали Inter, Onest, Manrope, Golos Text, Geologica, Wix Madefor и Montserrat на одной фразе с alfabank.ru при одинаковой ширине строки.

Шрифт подключён локально из пакета `@fontsource/onest` (начертания 400, 500, 700) и работает без интернета. Все шрифтовые токены дизайн-системы (`--font-family-system`, `--font-family-styrene`, `--font-family-alfasans`) указывают на Onest.

## Компоновка

Значения сняты со скриншотов alfabank.ru.

| Элемент | Как сделано | Значение |
|---|---|---|
| Шапка | Чёрная, белые пункты меню, активный пункт — тёмная плашка | `#000`, плашка `#1D1D1F` |
| Заголовок страницы | На чёрной полосе под шапкой, крупный жирный | Onest 700 |
| Контент | Белый «лист» со скруглёнными верхними углами поверх чёрной полосы | радиус 40 px |
| Блоки | Серые панели без теней | `#F2F3F5`, радиус 32 px |
| Карточки внутри панелей | Белые | радиус 20–24 px |
| Поля ввода и второстепенные кнопки на сером | Полупрозрачные токены дают нужные оттенки | `#E6E8EC`, `#DBDDE2` |
| Главное действие | Красная кнопка, одна на экран | `#EF3124` |
| Выбранный вариант (чипы, плитки) | Чёрная заливка или чёрная рамка | `#212124` |
| Основной текст | `rgba(3, 3, 6, 0.88)` | на белом ≈ `#212124` |
| Подвал кабинета клиента | Чёрное поле со скруглёнными верхними углами, разделы и ссылки как в подвале alfabank.ru для бизнеса — ведут на сайты банка в новой вкладке; внизу вместо юридического текста банка — пояснение, что это прототип | `#000`, радиус 40 px |

Стили карточек описаны парами «основной / второстепенный фон». Внутри контента эти два токена меняются местами ([global.css](../frontend/src/styles/global.css), правило `.page`), поэтому на любой глубине вложенности соседние уровни контрастны: белая страница → серая панель → белая карточка → серый блок.

## Принципы

- Одно главное действие на экране, всё остальное — второстепенные кнопки.
- Статус заявки и следующий шаг всегда вверху страницы заявки.
- Суммы — с неразрывными пробелами и знаком ₽, в таблицах — моноширинные цифры.
- Тексты для клиента — без банковского жаргона: «Проверяем заявку», «Ждём ответа бюро кредитных историй».
- Ошибки — плашкой рядом с действием, с понятной причиной.

## Экраны

| Раздел | Экран | Назначение |
|---|---|---|
| Стартовая страница и вход | `/login` | Кнопка «Войти» справа в шапке, как на alfabank.ru, открывает окно входа поверх размытой страницы: логин и пароль, быстрый вход под тестовыми учётными записями |
| Клиент | `/client` | Главная: приветствие и подбор кредита, заявки, требующие действия, список заявок, карточка компании |
| Клиент | `/client/new` | Мастер заявки: подбор продукта и расчёт, данные заявки, проверка и отправка |
| Клиент | `/client/applications/:id` | Заявка: текущий этап и действие, шаги проверки, предложение, подписание, кредит и график, чат, история, документы |
| Банк | `/bank` | Очередь заявок: счётчики, фильтры, поиск, срок рассмотрения |
| Банк | `/bank/applications/:id` | Досье и решение по заявке |
| Банк | `/bank/metrics` | Показатели конвейера: воронка, автоматизация, сроки, конверсия, причины отказов, продукты, аналитики |
| Банк | `/bank/pipeline` | Конвейер и сбои: состояние внешних систем, управление сбоями, сброс демо-данных |
| Банк | `/bank/audit` | Журнал действий |

Основная вёрстка — для экранов от 1280 px; организаторы уточнили, что адаптивность не обязательна, но считают её небольшим плюсом (ответ 14). Поэтому кабинет клиента адаптирован под телефон от 360 px: на ширине меньше 1024 px колонки перестраиваются в одну, меньше 768 px — компактнее шапка (знак без подписи, разделы прокручиваются, имя пользователя скрыто), отступы и скругления меньше, калькулятор и карточки продуктов идут друг под другом, шаги мастера прокручиваются внутри карточки. Сценарии клиента в Playwright проходят и на экране 390×844 (проект `mobile-client`). Рабочее место аналитика остаётся настольным: от 1024 px, на телефоне доступно с горизонтальной прокруткой таблиц.
